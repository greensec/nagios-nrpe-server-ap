nagios-nrpe-server-ap

A drop-in replacement for the Debian nagios-nrpe-server package, built from NRPE 4.1.3 with --enable-command-args, upstream post-4.1.3 backports and several rounds of security hardening.

Command arguments are enabled (dont_blame_nrpe=1): clients can pass arguments to the commands defined in nrpe.cfg via check_nrpe -a. Keep allowed_hosts restricted to your monitoring servers. The daemon requires TLS 1.2+ with non-anonymous ciphers on all shipped distributions.

Install

wget -O- https://greensec.github.io/nagios-nrpe-server-ap/scripts/add-repository.sh | bash
apt-get install nagios-nrpe-server-ap

Or grab a .deb from the releases and apt-get install ./nagios-nrpe-server-ap_*_amd64.deb.
